## 📚 Sobre o projeto

Este projeto reúne arquivos e exemplos utilizados para aprender os principais conceitos da linguagem **PHP**, desde fundamentos básicos até a construção de aplicações simples.

O objetivo é praticar programação web utilizando PHP e compreender como funciona a execução de scripts no servidor.

## 🚀 Como executar

### 1️⃣ Verifique se o PHP está instalado

No terminal:

```bash
php -v
```

Se o PHP estiver instalado, será exibida a versão disponível.

### 2️⃣ Clone o projeto

```bash
git clone git@github.com:ciepnejaneja/teste.git
```

Entre na pasta:

```bash
cd teste
```

### 3️⃣ Inicie o servidor PHP

```bash
php -S localhost:8000
```

Depois acesse no navegador:

```text
http://localhost:8000
```

## 💻 Exemplos

Um exemplo simples de PHP:

```php
<?php

$nome = "Aluno";
$idade = 18;

echo "Olá, $nome!";
echo "<br>";
echo "Você tem $idade anos.";

?>
```
